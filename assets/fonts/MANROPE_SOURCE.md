# Manrope source note

ELIXR packages the static Manrope weights 400, 500, 600, 700, and 800 from
`https://github.com/aaronbell/manrope` at pinned commit
`6f81ebecdf65e4463b798cc07b16a4f8d5216917`.

The upstream variable source at `fonts/variable/Manrope[wght].ttf` is the
byte-identical Google Fonts onboarding source (SHA-256
`d0639be45d0af36e798172419d7bd173c4bd4f29e2b76cbb69db1d11bf8b0a40`).
