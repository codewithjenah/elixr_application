# Geist source note

ELIXR packages the official static Geist Sans weights 400 through 900 that
the current UI requests, plus Geist Mono 500 for the small number of technical
confirmation phrases. The files come from the `vercel/geist-font` v1.7.2 tag
at commit `a73329da8fc62afc917f796555202e4997f79b7c`.
